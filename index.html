Flash Sale and Seat Reservation Engine (personal project)

Django • DRF • PostgreSQL • Redis • Celery • Docker

A backend service where many users compete for limited stock. A successful hold reserves stock for 10 minutes, and a signed payment webhook turns it into an order. I built four ways of reserving stock and load-tested each one with Locust. With 2 units in stock, the unguarded version created 48 holds; the other three created exactly 2. It also covers idempotent checkout and webhooks, Celery-based hold expiry, and 116 automated tests including 300-thread concurrency tests.
